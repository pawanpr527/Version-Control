## Version Control Using Git
<i>Git</i> is a open source distributed version control system, all users have copy of original project with state history, 
they can commit locally and then push changes in main repo.

#### Git commands : 
- git add file-name
- git commit -m "messege"
- git push origin branch-name
- git pull origin branch-name
- git checkout -b branch-name
- git checkout branch-name
- git status
